# Shorty - Сервис сокращения ссылок

Высокопроизводительный HTTP-сервис для создания и управления короткими ссылками с поддержкой статистики, rate limiting и конкурентной обработки запросов.

## ✨ Особенности

- **Создание коротких ссылок** - автоматическая генерация или пользовательский код
- **Редирект** - мгновенное перенаправление на оригинальный URL
- **Статистика** - подсчет переходов за все время и за последние 60 секунд
- **Rate Limiting** - ограничение количества созданий ссылок (10 в минуту)
- **TTL ссылок** - автоматическое удаление истекших ссылок
- **Graceful Shutdown** - корректное завершение с ожиданием фоновых задач
- **Конкурентная безопасность** - атомарные операции без гонок данных
- **Единый формат ошибок** - все ошибки возвращаются в едином JSON формате
- **Request ID** - каждый запрос получает уникальный идентификатор для трассировки

## 🏗️ Архитектура

Проект организован как cargo workspace с четким разделением на слои:
├── crates/
│ ├── domain/ # Доменный слой (сущности, контракты)
│ ├── storage/ # Слой хранения данных (InMemory, DashMap)
│ └── shorty-server/ # HTTP слой (axum handlers, middleware)
├── Cargo.toml # Workspace конфигурация
└── README.md


### Слои архитектуры:

1. **Domain** - чистые доменные модели и контракты без внешних зависимостей
2. **Storage** - реализации хранилища с конкурентными структурами данных
3. **Server** - HTTP API с middleware и обработчиками запросов

## 🚀 Установка и запуск

### Требования

- Rust 1.75+
- Cargo

### Сборка

```bash
# Клонирование репозитория
git clone <repository-url>
cd shorty

# Сборка всех компонентов
cargo build --workspace --release

# Запуск сервера
cargo run --release --package shorty-server
